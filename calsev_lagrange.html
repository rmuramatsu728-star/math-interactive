数式で確認する / 正則性と「等高線が接する」の注意

f, g は開集合上で C¹ 級とする. g(P) = 0, ∇g(P) ≠ 0 のとき, 制約曲線はPの近傍で正則にパラメータ表示 γ(t) できる. g(γ(t)) = 0 を微分すると ∇g(γ(t)) · γ′(t) = 0. また (f ∘ γ)′(t) = ∇f(γ(t)) · γ′(t). よって制約付き極値では ∇f(P) が接線に直交し, ∇f(P) = λ∇g(P) となる.

さらに ∇f(P) ≠ 0 なら f = f(P) も局所的に正則な曲線で, 両方の等高線の接線が一致する. ∇f(P) = 0 の場合も λ = 0 で未定乗数条件は成立するが, f の等高線が正則とは限らないため, 単純な「2曲線が接する」という説明は使えない.

∇g(P) = 0 の点ではこの議論は適用できない. また, 第3例の t ∈ [−1.5, 1.5] などは表示範囲であり, 端点を制約付き極値の候補として扱うわけではない. 候補点への移動ボタンは各例の厳密な候補を使い, 画面上の「ほぼ0」は数値表示上の目安と区別している.
